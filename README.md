## Getting Started

To run this project locally:

```bash
git clone <repository-url>
cd tejas-prajapati-portfolio
npm install
npm run dev
```

The development server will run at: `http://localhost:3000`

## Environment Variables

No environment variables are currently required for the portfolio frontend.

## Development Commands

- `npm run dev` - Starts the local development server.
- `npm run build` - Creates an optimized production build.
- `npm run start` - Starts the production server (requires build first).
- `npm run lint` - Runs ESLint to catch and fix code issues.

## Performance

The project uses performance-conscious techniques including:
- Optimized server-side rendering (SSR/SSG) where possible
- Responsive 3D rendering with Device Pixel Ratio (DPR) limits
- Optimized GSAP animations isolated in React contexts
- Lazy loading where appropriate
- Optimized `next/image` handling
- Minimal unnecessary client-side logic
